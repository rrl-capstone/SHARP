# Images

Slides, diagrams, and result screenshots made by hand or kept as a record, grouped by the
part of the work they explain.

| Folder | What's inside |
|---|---|
| `phase0_eda/` | DBeaver screenshots of the queries in `exploration/initial_queries/` |
| `phase1_eligibility/` | Slide explaining the eligibility rules (from the earlier pipeline) |

Naming rules, so new images stay consistent:

- One folder per topic, lowercase with underscores.
- Inside a folder, number files in the order you'd present them: `01_...png`, `02_...png`.
- No spaces, so links in Markdown don't break.

Plots made by the pipeline go to `results/<run>/<stage>/` instead, because they are
regenerated on every run.
